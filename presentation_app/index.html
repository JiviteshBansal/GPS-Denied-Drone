Capstone Project Presentation

Autonomous Exploration in GPS-Denied Environments

A Complete Simulation Autonomy Stack using ROS 2, Gazebo Harmonic, and PX4 SITL

🚨 Problem Statement

Standard unmanned aerial vehicles (UAVs) rely on satellite GNSS/GPS for global position estimation. In critical real-world operations, GPS is severely degraded or completely unavailable:

  • Subterranean & Caves: Underground rescue and search operations.
  • Indoor Structures: Collapsed buildings, warehouses, and industrial plants.
  • Urban Canyons & Jamming: Dense infrastructure or intentional GPS denial.

🎯 Project Goal & Solution

Build an end-to-end, 100% autonomous exploration drone that:

  1. Localizes without external positioning systems via onboard depth camera and IMU.
  2. Incrementally generates a 2D/3D Occupancy Grid map in real time.
  3. Autonomously detects boundary frontiers between known and unknown space.
  4. Clusters and ranks candidate regions using an information-gain scoring algorithm.
  5. Generates collision-free waypoints and navigates until full exploration is achieved.

Milestone M4

Real-Time Occupancy Grid Mapping

Converting Depth Sensor Observations into Probabilistic 2D Maps

📐 Sensor Projection & Raycasting

The simulated depth sensor captures per-pixel distances $z$. Using pinhole projection parameters:

x_cam = (u - cx) * z / fx
y_cam = (v - cy) * z / fy
P_world = R_drone * P_cam + T_drone

For each projected point, Bresenham's Line Algorithm clears intermediate cells to FREE (0) and marks the obstacle hit cell as OCCUPIED (100).

🗂️ Grid State Representation

Cell ValueStateInterpretation
-1UNKNOWNUnobserved space requiring exploration
0FREETraversable free space for flight
100OCCUPIEDPhysical obstacles, walls, or boundaries

Performance: Updates full 400x400 grid in <15ms per frame at 2 Hz.

Milestones M5 & M6

Frontier Detection & Connected Component Clustering

Transforming raw grid cells into actionable exploration target regions

🔍 Frontier Cell Detection (M5)

A cell $(x, y)$ is classified as a Frontier if and only if:

  1. It is in state FREE (0) (the drone can safely occupy it).
  2. At least one of its 8-connected neighbors is in state UNKNOWN (-1).

This forms continuous boundary contours separating explored territory from the unknown environment.

🧩 BFS Clustering (M6)

Individual frontier cells are noisy and too small to fly to. We apply Breadth-First Search (BFS) connected-component labeling:

  • Groups contiguous frontier cells into discrete clusters $\{C_1, C_2, \dots, C_k\}$.
  • Computes the physical centroid $(\bar{x}, \bar{y})$ of each cluster: $$\bar{x} = \frac{1}{|C|} \sum_{(gx, gy) \in C} (origin_x + gx \cdot res)$$
  • Filters out small noise clusters below minimum size threshold ($N < 5$).
Milestone M7

Frontier Scoring & Target Selection

Balancing Maximum Information Gain with Minimum Flight Energy Cost

⚖️ Objective Utility Function

For each detected cluster $C_i$ with centroid $p_{C_i}$ and drone position $p_{drone}$:

$$\text{Score}(C_i) = \text{InformationGain}(C_i) - \lambda \cdot \text{DistanceCost}(C_i, p_{drone})$$
  • Information Gain: Measured by cluster size $|C_i|$ (number of frontier cells).
  • Distance Cost: Euclidean distance $\|p_{C_i} - p_{drone}\|_2$.
  • Weight Parameter $\lambda$: Balances travel efficiency vs greediness ($\lambda = 0.1$).

🎯 Deterministic Selection Policy

  1. Compute scores for all clusters satisfying $|C| \ge \text{min\_size}$.
  2. Select the optimal cluster: $C^* = \arg\max_{C} \text{Score}(C)$.
  3. Publish target centroid as ROS 2 PointStamped on /exploration/selected_frontier.
  4. Ties broken deterministically by smaller cluster ID.
Milestones M8 – M10

Waypoint Generation & Closed-Loop Autonomy

Executing Safe Trajectories via PX4 Offboard Mode

🧭 Collision-Free Waypoint Generation (M8)

  • Validates that target centroid is in free space with safety clearance ($>0.5\text{m}$ from obstacles).
  • If centroid falls on obstacle or unknown cell, pulls waypoint along vector towards current drone position.
  • Sets target altitude to designated exploration height ($1.5\text{m}$).

🔄 Full Exploration State Machine (M10)

TAKEOFF ➔ MAP_UPDATE ➔ DETECT_FRONTIERS ➔ SCORE_AND_SELECT ➔ OFFBOARD_FLY ➔ CHECK_TERMINATION

Termination Conditions:

  • No reachable frontiers remaining (Environment 100% Explored).
  • Coverage threshold reached ($>95\%$ free/occupied).
  • Safety/Battery limits reached.
